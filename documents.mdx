The **Documents** tab is your library. It holds two kinds of files:

1. **Generated documents**: produced by tasks. You don't upload these; they're created when you finish an interview.
2. **Uploaded documents**: PDFs, Word docs, markdown, text files you drop in yourself.

Both kinds can be attached to project chats as context using the document picker.

## Uploading

Hit **Upload**, pick a file. Supported types: `.pdf`, `.docx`, `.txt`, `.md`. The app extracts the text in the background so the AI can read it later. Big files take a few seconds.

## Groups

A **group** is a labeled collection of documents. Useful when you have a bunch of related files you always want to pull into a chat together (e.g. "Q4 campaign assets" or "Client X background").

Create a group, drop documents into it, and when you're in a chat you can select the whole group from the document picker. Every doc in that group gets attached to the conversation in one click.

A document can live in multiple groups. Groups don't move the file; they're just labels.

## Deleting

Trash icon on the doc. Deleted = gone. Generated documents from tasks can also be deleted from inside the task itself (the document viewer page has a delete button).

If you delete a generated document, it stops being injected into projects that listed that task as a prerequisite. You can regenerate by restarting the task.

## Attaching docs to a chat

In any chat, click the paperclip icon in the input area to open the document picker. Pick individual docs or whole groups. Selected docs are sent to the AI as part of the conversation context for that session.

This is *additive*; you're adding docs on top of whatever prereq-task documents are already injected automatically.
